**Q47.** What is printed by the recursive routine?
```text
Function solve(Integer n)
    If (n <= 1)
        Return 1
    End If
    Return n * solve(n - 2)
End Function

Integer res = solve(5)
Print res
```
- (A) 15  
- (B) 120  
- (C) 25  
- (D) 30
