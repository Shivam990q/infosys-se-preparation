# The Internal Bridge to DSE & SP Program: Fast-Track CTC Doubling

**Current Role:** Systems Engineer (JL3 | ₹3.60 LPA)  
**Target Roles:** Digital Specialist Engineer (DSE | ₹6.25 LPA) | Specialist Programmer (SP | ₹9.50 LPA)  
**Program Frequency:** Conducted Quarterly / Bi-Annually on the **Lex** Platform  
**The Golden Opportunity:** Jump from ₹3.60 LPA to ₹6.25 LPA or ₹9.50 LPA internally without waiting 3–4 years for standard annual promotion cycles.

---

To appear for the internal Bridge examination, an engineer must fulfill:

```
+---------------------------------------------------------------------------------+
|                         BRIDGE PROGRAM ELIGIBILITY MATRIX                       |
+-------------------+-------------------------------------------------------------+
| Parameter         | Mandatory Requirement                                       |
+-------------------+-------------------------------------------------------------+

|                   | Systems Engineer (JL3) at Infosys.                          |
+-------------------+-------------------------------------------------------------+
| 2. Appraisal      | Performance rating of **"Meets Expectations" (ME)** or     |
|    Rating         | **"Exceeds Expectations" (EE)** in the previous cycle.      |
+-------------------+-------------------------------------------------------------+
| 3. Project Status | Must be billed on an active delivery project (cannot be on  |
|                   | the bench at the time of formal nomination).                |
+-------------------+-------------------------------------------------------------+

|    Pre-requisites | platform, including completion of the "Advanced DSA Track". |
+-------------------+-------------------------------------------------------------+
| 5. PM Nomination  | Written sign-off from your Project Manager / Unit SPOC.     |
+-------------------+-------------------------------------------------------------+
```

## 2. Assessment Architecture & Score Benchmarks

The exam is conducted via **HackerEarth** under strict proctored conditions:

```
+---------------------------------------------------------------------------------+
|                       BRIDGE CODING ASSESSMENT STRUCTURE                        |
+------------------+-----------+----------+---------------------------------------+
| Problem Tier     | Points    | Time     | Algorithmic Concepts Tested           |
+------------------+-----------+----------+---------------------------------------+
| 1. Easy Problem  | 20 Pts    | ~30 mins | String parsing, Arrays, HashMaps,     |
|                  |           |          | Two-Pointer greedy techniques.        |
+------------------+-----------+----------+---------------------------------------+
| 2. Medium Problem| 35 Pts    | ~60 mins | Binary Trees, Sliding Window, DFS/BFS |
|                  |           |          | Grid traversal, Recursion with Memo.  |
+------------------+-----------+----------+---------------------------------------+
| 3. Hard Problem  | 45 Pts    | ~90 mins | 1D/2D Dynamic Programming, Shortest   |
|                  |           |          | Path (Dijkstra), Disjoint Set Union.  |
+------------------+-----------+----------+---------------------------------------+
| TOTAL            | 100 Pts   | 3 Hours  | Languages: Java, Python, C++, C#      |
+------------------+-----------+----------+---------------------------------------+
```

### Qualifying Score Thresholds:
- **Bridge to DSE (₹6.25 LPA):** Scoring **$\ge 50$ to 65 Points** (Solving Problem 1 completely + Problem 2 partial/full test cases).
- **Bridge to SP (₹9.50 LPA):** Scoring **$\ge 75$ to 100 Points** (Solving all 3 problems or 2 completely with full hidden test cases).

## 4. Post-Selection Transition & Revised Compensation

Once the interview is cleared:
1. **Title Change:** Your Job Level changes on Sparsh from **Systems Engineer (JL3)** to **Digital Specialist Engineer (JL3)** or **Specialist Programmer (JL3)**.
2. **Salary Revision:** Your revised CTC (₹6.25 LPA or ₹9.50 LPA) is updated in the subsequent monthly payroll cycle, with net take-home pay jumping from ~₹25,000 to **~₹45,000 / month (DSE)** or **~₹70,000 / month (SP)**.
3. **Project Reassignment:** You are reassigned by RMG to high-complexity technical projects (Cloud Native Microservices, AI/ML Engineering, Distributed Backend Systems).
