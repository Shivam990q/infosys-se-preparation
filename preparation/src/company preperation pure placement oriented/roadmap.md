# THE ULTIMATE FAANG PLACEMENT ROADMAP (PURE PLACEMENT ORIENTED) 🚀
*From Absolute Zero to FAANG Engineer - The Resource-Heavy Master Guide*

This document is your single source of truth. It contains the exact sequence, the exact platforms, and the exact books/channels you need to crack top-tier companies (FAANG, Uber, LinkedIn, Stripe, etc.).

---

## 🟢 PHASE 0: PROGRAMMING LANGUAGE MASTERY (Weeks 1-3)
You must pick **ONE** language and know its inner workings, memory management, and standard libraries (STL/Collections). Do not switch languages later.

**Which Language?**
*   **C++:** Best for raw speed, widely used in competitive programming. (Highly Recommended)
*   **Java:** Enterprise standard, excellent for Object-Oriented Design. (Highly Recommended)
*   **Python:** Concise, saves time in interviews, great for AI/Backend.

**🔥 TOP RESOURCES:**
*   **C++:** 
    *   *Website:* [LearnCpp.com](https://www.learncpp.com/) (The absolute bible for C++)
    *   *YouTube:* CodeHelp by Love Babbar, The Cherno (for deep memory concepts)
*   **Java:** 
    *   *Course:* [MOOC.fi Java Programming](https://java-programming.mooc.fi/) (University of Helsinki - Best hands-on course)
    *   *YouTube:* Kunal Kushwaha (Java Bootcamp)
*   **Python:** 
    *   *YouTube:* Corey Schafer (Advanced Python concepts)
    *   *Book:* Automate the Boring Stuff with Python

## 🟡 PHASE 1: DATA STRUCTURES & ALGORITHMS (DSA) FOUNDATIONS (Months 1-3)
This is the core. 70% of your interview rounds will test this.

**Topics to Master:**
1.  Big O Notation (Time & Space Complexity)
2.  Arrays, Strings, 2D Matrices
3.  Binary Search (Finding answers on monotonic functions)
4.  Linked Lists, Stacks, Queues
5.  HashMaps, HashSets

**🔥 TOP RESOURCES:**
*   **Sheet/Tracker:** [Striver’s A2Z DSA Course/Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2) (Follow this blindly for structure).
*   **Platform:** LeetCode (Do not use HackerRank or CodeChef for FAANG prep. Stick to LeetCode).
*   **Video Explanations:** 
    *   [NeetCode](https://www.youtube.com/c/NeetCode) (For LeetCode problem breakdowns)
    *   Aditya Verma (YouTube - specifically for his legendary Stack and Binary Search playlists)

---

## 🟠 PHASE 2: ADVANCED DSA & FAANG PATTERNS (Months 4-6)
FAANG companies test your ability to recognize *patterns*, not your ability to memorize solutions. 

**Core Patterns to Master:**
1.  Sliding Window (Fixed & Variable)
2.  Two Pointers & Fast/Slow Pointers
3.  Trees (BST, AVL, Traversals)
4.  Graphs (BFS, DFS, Dijkstra, Topological Sort, Kruskal’s)
5.  Dynamic Programming (1D, 2D, DP on Trees, Knapsack, LCS)
6.  Recursion & Backtracking
7.  Tries, Heaps (Priority Queue)

**🔥 TOP RESOURCES:**
*   **The Ultimate Problem List:** [NeetCode 150](https://neetcode.io/) & [Grind 75](https://www.techinterviewhandbook.org/grind75)
    *   *Rule:* Solve these 150 problems 2-3 times until you can see the pattern instantly.
*   **Dynamic Programming Mastery:** Aditya Verma’s DP Playlist (YouTube) - 50 videos, absolute gold.
*   **Graph Mastery:** Striver's Graph Series (YouTube).
*   **Pattern Recognition Text Guide:** [AlgoMonster](https://algo.monster/) or Educative.io's *Grokking the Coding Interview: Patterns for Coding Questions*.

## 🔴 PHASE 3: COMPETITIVE PROGRAMMING (Optional but Recommended for Google/Directi/CodeNation)
If you are targeting Google, purely doing LeetCode might not be enough. You need speed and edge-case thinking.

*   **Platform:** Codeforces (Aim for 1400-1600 Rating).
*   **Resource:** [CSES Problem Set](https://cses.fi/problemset/) (Great for raw algorithmic thinking).
*   **Contests:** Give LeetCode Weekly & Bi-weekly contests religiously. It builds pressure tolerance.

## 🟣 PHASE 4: OBJECT-ORIENTED DESIGN (LLD / Machine Coding) (Month 7)
Low-Level Design (LLD) is crucial for SDE-1 and SDE-2 roles at Amazon, Uber, Flipkart, etc.

**Concepts to Master:**
1.  SOLID Principles.
2.  Design Patterns (Singleton, Factory, Observer, Strategy, Decorator).
3.  UML Diagrams.
4.  Machine Coding (Writing fully functional code for a problem like "Design a Parking Lot" in 90 minutes).

**🔥 TOP RESOURCES:**
*   **Website:** [Refactoring.Guru](https://refactoring.guru/) (Best visual guide for Design Patterns).
*   **Book:** Head First Design Patterns.
*   **Course:** Educative.io - *Grokking the Object-Oriented Design Interview*.
*   **YouTube:** Keerti Purswani (LLD playlist), Udit Agarwal (Machine Coding).

---

## 🔵 PHASE 5: SYSTEM DESIGN (HLD) (Month 8-9)
High-Level Design separates the junior engineers from the mid-level/senior engineers. 

**Concepts to Master:**
Scaling, Load Balancing, Caching (Redis), CAP Theorem, Microservices vs Monoliths, Database Sharding, Message Queues (Kafka/RabbitMQ).

**🔥 TOP RESOURCES:**
*   **The Bible (Book):** *Designing Data-Intensive Applications* by Martin Kleppmann. (Read this cover to cover).
*   **Visual Guide (Book/Web):** *System Design Interview* by Alex Xu ([ByteByteGo.com](https://bytebytego.com/)).
*   **YouTube:** Gaurav Sen (System Design Playlist), Hussein Nasser (Backend Engineering), InfoQ (For real company architecture talks).

---

## 🟤 PHASE 6: CORE CS SUBJECTS (Month 10)
Usually asked in the first 15 mins of a tech round or in Online Assessments (OAs).

**🔥 TOP RESOURCES:**
*   **Operating Systems (OS):** Gate Smashers (YouTube), Neso Academy. (Focus on Deadlocks, Multithreading, Paging).
*   **Database Management Systems (DBMS):** Gate Smashers. (Focus on ACID properties, Normalization, Joins, Indexing).
*   **Computer Networks (CN):** Neso Academy. (Focus on OSI Model, TCP/UDP, DNS, HTTP/HTTPS).
*   **Practice MCQs:** GeeksforGeeks and Sanfoundry.

---

## 🟢 PHASE 7: HEAVYWEIGHT PROJECTS (Month 10-11)
Your resume gets shortlisted based on your projects. Skip simple Todo apps. 

**Build 2 High-Impact Projects:**
1.  **System-Heavy Project:** E.g., A distributed chat application using WebSockets, Kafka, and Redis caching.
2.  **Full-Stack Scale Project:** E.g., An e-commerce API with Stripe payment integration, JWT Auth, deployed on AWS using Docker.

**🔥 TOP RESOURCES:**
*   **Full Stack Mastery:** [The Odin Project](https://www.theodinproject.com/) or [Full Stack Open](https://fullstackopen.com/en/).
*   **DevOps/Deployment:** TechWorld with Nana (YouTube - Learn Docker & CI/CD basics).

## 🌟 PHASE 8: THE RESUME, COLD EMAILS & INTERVIEW SIMULATION (Month 12)
If you don't get interviews, all the prep is useless.

**1. The Resume:**
*   Use the **Jake’s Resume Template** (Overleaf). It is 100% ATS-friendly.
*   Use the XYZ format: *"Accomplished [X] as measured by [Y], by doing [Z]"*.

**2. Mock Interviews (CRITICAL):**
*   **Platform:** [Pramp.com](https://www.pramp.com/) (Free peer-to-peer mock interviews). Give at least 15-20 mocks before your real interview.
*   **Premium Mocks:** [Interviewing.io](https://interviewing.io/) (Mock with real FAANG engineers).

**3. Behavioral Preparation (Leadership Principles):**
*   **Amazon Leadership Principles:** Read about them. They are asked in almost every FAANG.
*   **The STAR Method:** Answer questions using Situation, Task, Action, Result.
*   **Resource:** [Tech Interview Handbook](https://www.techinterviewhandbook.org/behavioral-interview/) (Goldmine for behavioral prep).

**4. Referrals:**
*   Cold email recruiters on LinkedIn. Search for "Technical Sourcer at Google" or "Engineering Manager at Amazon". 
*   Message format: *Short intro + Your strongest achievement + Link to resume + Ask for referral for Job ID XYZ*.
