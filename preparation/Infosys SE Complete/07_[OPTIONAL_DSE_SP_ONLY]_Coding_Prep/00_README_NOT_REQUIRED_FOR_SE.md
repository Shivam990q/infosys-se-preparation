> **Zero Live Coding is tested in the Infosys SE Exam or Interview.**

---

### 🚫 Why Infosys SE Does NOT Need This Module:
1. **Round 1 (Written Exam / Online Assessment)**:
   - There is **NO live coding compiler** (no LeetCode, HackerRank, or IDE).
   - Candidates are **NOT** required to write or compile code.
   - All technical evaluation is strictly conducted via **Section 4: Pseudo Code** (only **5 Multiple Choice Questions** focusing on manual dry-run loop tracing and bitwise operator prediction).
2. **Round 2 (Technical Interview)**:
   - Evaluates basic Object-Oriented Programming (OOP) definitions, basic SQL queries (e.g. 2nd highest salary), and college final-year project defense.
   - Candidates are **never** asked to solve LeetCode Medium/Hard Dynamic Programming or Graph problems.

---

### ❓ Why Is This Folder Present in the Vault?
This folder exists purely because **CampusMonk** packaged their general training curriculum into the course archive (`1.0 LIVE_ Infosys Prep` by Amogh Sir):
1. **For DSE / SP Candidates**: Infosys offers higher-tier differential hiring tracks — **Digital Specialist Engineer (DSE — 6.5 LPA)** and **Specialist Programmer (SP — 9.5 LPA)** — which require live hands-on DSA coding on HackerRank.
2. **Post-Selection Mysore Bridge**: After candidates are selected for SE, they undergo mandatory training at the Infosys Mysore campus, where they eventually take Python/Java Foundation Assessments (FA).
