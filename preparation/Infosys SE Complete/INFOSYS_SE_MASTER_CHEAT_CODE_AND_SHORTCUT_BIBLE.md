### 1.4 Expenditure Invariance & Successive Percentage Changes
- **Successive Change Formula:**
  $$\text{Net Change} = a + b + \frac{a \times b}{100}\%$$
  *(Note: Put negative sign for decrease/discount. Two successive discounts of $20\%$ and $10\% = -20 - 10 + \frac{200}{100} = -28\%$)*
- **Price-Consumption Elasticity Shortcut:**
  $$\text{If Price increases by } R\% \implies \text{Consumption must decrease by } \left(\frac{R}{100 + R}\right) \times 100\%$$
  $$\text{If Price decreases by } R\% \implies \text{Consumption can increase by } \left(\frac{R}{100 - R}\right) \times 100\%$$
  *Example:* Price of sugar rises by $25\% (\frac{1}{4}) \implies$ Consumption decreases by $\frac{1}{4+1} = \frac{1}{5} = \mathbf{20\%}$.

### 3.3 Bitwise Operators & Precedence Fast-Locks

| Operator | Symbol | Rule & Exam Invariant | Identity Properties |
| :---: | :---: | :--- | :--- |
| **Bitwise AND** | `&` | `1` ONLY when BOTH bits are `1`. | $x \& 0 = 0$, $x \& x = x$, $x \& (x-1)$ clears lowest set bit |
| **Bitwise OR** | `\|` | `1` when EITHER or BOTH bits are `1`. | $x \| 0 = x$, $x \| x = x$ |
| **Bitwise XOR** | `^` | `1` when bits are DIFFERENT; `0` when same. | $\mathbf{x \oplus x = 0}$, $\mathbf{x \oplus 0 = x}$, associative & commutative |
| **Bitwise NOT** | `~` | Inverts all bits. Formula: $\mathbf{\sim x = -(x + 1)}$. | $\sim 5 = -6$, $\sim 0 = -1$, $\sim (-1) = 0$ |
| **Left Shift** | `<< n` | Multiplies integer by $2^n$. | $x \ll 1 = 2x$, $5 \ll 3 = 5 \times 2^3 = 5 \times 8 = \mathbf{40}$ |
| **Right Shift** | `>> n` | Integer division by $2^n$. | $x \gg 1 = \lfloor x/2 \rfloor$, $40 \gg 3 = 40 / 8 = \mathbf{5}$ |

#### ⚠️ Increment & Decrement Trap Invariants:
- **Pre-Increment (`++x`):** Increment FIRST, then use new value in evaluation.
- **Post-Increment (`x++`):** Use current value in evaluation FIRST, then increment.
- *Example:* `int a = 5; int b = ++a + a++;` $\implies ++a$ makes $a=6$ (used as 6); $a++$ uses 6 then becomes 7. Thus $b = 6 + 6 = 12$, and final $a = 7$!

# ⏱️ SECTION 4: QUANTITATIVE APTITUDE SPEED SHORTCUTS

### 4.1 Time & Work: The Total-Work LCM Method
Forget unitary fractions $\frac{1}{A} + \frac{1}{B}$. Use **Total Work Units**:
1. Take $\text{LCM}$ of given individual days as **Total Work Units**.
2. Calculate **Daily Efficiency** = $\frac{\text{Total Work}}{\text{Days}}$.
3. Required Days = $\frac{\text{Total Work}}{\text{Combined Efficiency}}$.

*Example:* A does work in 12 days, B in 15 days.
- $\text{Total Work} = \text{LCM}(12, 15) = 60 \text{ units}$.
- A's rate = $60 / 12 = 5 \text{ units/day}$.
- B's rate = $60 / 15 = 4 \text{ units/day}$.
- Combined rate = $5 + 4 = 9 \text{ units/day}$.
- Total time = $\frac{60}{9} = \frac{20}{3} = \mathbf{6\frac{2}{3} \text{ days}}$. (Instant mental calculation!)

#### ⚡ Man-Days-Hours Formula:
$$\mathbf{\frac{M_1 \times D_1 \times H_1}{W_1} = \frac{M_2 \times D_2 \times H_2}{W_2}}$$

### 4.4 Rule of Alligation (Mixtures & Averages)
Used whenever two varieties of different costs/percentages are mixed:
```
  Cheaper Price (C)            Dearer Price (D)
              \              /
               Mean Price (M)
              /              \
         (D - M)     :      (M - C)
```
$$\mathbf{\frac{\text{Quantity of Cheaper}}{\text{Quantity of Dearer}} = \frac{D - M}{M - C}}$$

### 5.1 Syllogisms: The 100-50 Tick-Cross Rules
Eliminate Venn diagram ambiguity using categorical distribution values:

| Proposition Statement | Subject Value | Predicate Value | Nature |
| :--- | :---: | :---: | :---: |

#### 3 Iron Rules of Syllogisms:
1. **Middle Term Rule:** The common middle term MUST be 100 in at least one premise.
2. **Sign Rule:** $(+) + (+) = (+)$; $(+) + (-) = (-)$; $(-)$ and $(-)$ yield NO valid conclusion.
3. **Income-Expense Rule:** A term distributed (100) in conclusion MUST be distributed (100) in premises. You cannot spend 100 if you only earn 50!

### 5.2 Data Sufficiency: 3-Step Rapid Decision Flowchart
Standard Infosys Data Sufficiency question structure:
1. **Step 1:** Test **Statement I alone**.
   - If sufficient $\implies$ Answer is **A** or **D**.
   - If not sufficient $\implies$ Answer is **B**, **C**, or **E**.
2. **Step 2:** Test **Statement II alone**.
   - If Statement I was sufficient and II is ALSO sufficient $\implies$ **Option D** (Each alone).
   - If Statement I was sufficient and II is NOT $\implies$ **Option A** (I alone).
   - If Statement I was NOT sufficient and II is sufficient $\implies$ **Option B** (II alone).
3. **Step 3:** If neither alone is sufficient, **combine Both Statements (I + II)**.
   - If together they give a unique answer $\implies$ **Option C** (Together sufficient).
   - If still insufficient $\implies$ **Option E** (Neither sufficient).

# 📚 SECTION 6: VERBAL ABILITY & GRAMMAR INVARIANTS

### 6.1 Core Subject-Verb Agreement Rules
1. **Neither..Nor / Either..Or:** Verb agrees with the **closest (nearer) subject**.
   - *Neither the manager nor the **employees are** present.*
   - *Either the players or the **coach is** responsible.*
2. **Parenthetical Phrases:** Words like *along with, together with, as well as, in addition to, accompanied by* do NOT change the number of the subject.
   - *The teacher, along with all her students, **was** present.* (Subject is "teacher" = Singular!)
3. **Indefinite Pronouns:** *Each, every, either, neither, one of the, anyone, everyone* ALWAYS take **Singular Verbs**.
   - *Each of the participants **has** submitted the report.* (NOT 'have')
4. **Collective Nouns:** Singular when acting as a unified body (*The jury **has** delivered its verdict*); Plural when individual members act separately (*The jury **were** divided in their opinions*).
