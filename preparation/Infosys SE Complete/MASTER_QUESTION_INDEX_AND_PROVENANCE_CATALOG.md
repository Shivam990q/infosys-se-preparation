## 🔍 3. How to Instantly Locate Any Question & Trace Its Provenance

Agar aap kisi bhi question ka snippet, keyword, ya ID denge, to `find_question.py` aur master SQLite database se turant pata chal jayega ki:
1. **Kis Folder aur File me hai:** Exact relative file path.
2. **Kis Line number par hai:** Exact start line aur end line.
3. **Kahan se uthaya gaya hai (Origin):** Topmate, CampusMonk Day X, PrepInsta, College ITM Exam Paper, ya Actual Slot (Oct 2, Oct 11, etc.).
4. **Options, Answer aur Solution kya hai:** Complete step-by-step mathematical derivation aur figure path.

### Example CLI Queries:
```bash
# 1. Search by exact phrase or words
python find_question.py "wrong letter in the following series"

# 2. Search by Question ID
python find_question.py --id "SEC01_MOD01_Q01"

# 3. Search questions from a specific origin
python find_question.py --source "Topmate" --limit 3

# 4. Search within a specific section
python find_question.py "circular table" --section "Reasoning"
```
