Question 1

In a certain code language, 'OM' is coded as 56 and 'GOT' is coded as 126. How will 'CARD' be coded in that language?

  • (A)

    104

  • (B)

    144

    CORRECT
  • (C)

    140

  • (D)

    142

Correct Answer: B
Explanation:

OM = (15+13)*2 = 56

GOT = (7+15+20)*3 = 126

CARD = (3+1+18+14) * 4 = 144

Question 2

If "JUNGLE" is coded as "KVOIMF", how is "FOREST" coded?

  • (A)

    GPQTFV

  • (B)

    GPQTFW

  • (C)

    GPQTFX

  • (D)

    GPQTFU

    CORRECT
Correct Answer: D
Explanation:

Each letter is shifted forward by 1 position:

J→K, U→V, N→O, G→H, L→M, E→F.

Similarly,

FOREST → F→G, O→P, R→S, E→F, S→T, T→U → GPQTFU.
