# ⏱️ Infosys Systems Engineer (SE) — Official Sectional Mock Test Series

> **Assessment Format:** Timed Sectional Proctored Computer-Based Assessment  
> **Sectional Independence:** Strict countdown timer per section. Unused time does not carry forward.  
> **Sectional Cutoffs:** Mandatory 65%–70% independent cutoff per section.  
> **Marking Scheme:** +1 mark per correct answer (2 or 3 marks for advanced grid puzzles). **Zero Negative Marking.**
