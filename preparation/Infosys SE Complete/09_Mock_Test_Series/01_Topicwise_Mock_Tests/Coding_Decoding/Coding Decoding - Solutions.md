### Question 1

In
a certain code language, 'OM' is coded as 56 and 'GOT' is coded as
126. How will 'CARD' be coded in that language?

**Options:**

- (A) 104
- ✅ **(B) 144** *(Correct Answer)*
- (C) 140
- (D) 142

**Correct Answer:** (B)

**Explanation / Solution:**
OM = (15+13)*2 = 56
GOT = (7+15+20)*3 = 126
CARD = (3+1+18+14) * 4 = 144
