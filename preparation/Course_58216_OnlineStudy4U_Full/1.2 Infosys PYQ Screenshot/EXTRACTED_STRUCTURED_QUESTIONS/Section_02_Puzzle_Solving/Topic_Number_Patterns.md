### Question 1 [Source: `photo_983@28-10-2024_22-33-04.jpg`, `photo_984@28-10-2024_22-34-34.jpg`]
**Question:** Given is a set of numbers that relate to each other in a certain logic. Assume the third set works just like the first two sets:
* **Set 1:** $(12, 36, 108)$
* **Set 2:** $(15, 45, 135)$
* **Set 3:** $(18, 54, ?)$

**Answer Options:**
* **(A)** 162
* **(B)** 172
* **(C)** 180
* **(D)** 196

**Correct Answer:** **(A) 162**  
**Mathematical Solution:**
* Each term is obtained by multiplying the previous term by 3 (Geometric Progression with $r = 3$):
  * Set 1: $12 \times 3 = 36$, $36 \times 3 = 108$.
  * Set 2: $15 \times 3 = 45$, $45 \times 3 = 135$.
  * Set 3: $18 \times 3 = 54$, $54 \times 3 = \mathbf{162}$.
Hence, the missing number is **162**.

### Question 2 [Source: `photo_967@28-10-2024_22-33-04.jpg`, `photo_986@28-10-2024_22-33-04.jpg`]
**Question:** Given is a set of four numbers that relate to each other in a certain logic. Assume the third set works just like the first two sets:
* **Set 1:** $(3, 9, 27, 81)$
* **Set 2:** $(2, 8, 32, 128)$
* **Set 3:** $(4, 16, 64, ?)$

**Answer Options:**
* **(A)** 216
* **(B)** 256
* **(C)** 512
* **(D)** 1024

**Correct Answer:** **(B) 256**  
**Mathematical Solution:**
* **Set 1:** Powers of 3: $3^1 = 3, 3^2 = 9, 3^3 = 27, 3^4 = 81$ (Common ratio $= 3$).
* **Set 2:** Powers of 2 (shifted): $2 \times 4 = 8, 8 \times 4 = 32, 32 \times 4 = 128$ (Common ratio $= 4$).
* **Set 3:** Geometric series with initial term $a = 4$ and common ratio $r = 4$:
  * Term 1: $4$
  * Term 2: $4 \times 4 = 16$
  * Term 3: $16 \times 4 = 64$
  * Term 4: $64 \times 4 = \mathbf{256}$
Hence, the missing value is **256**.

### Question 3 [Source: `photo_990@28-10-2024_22-34-34.jpg`]
**Question:** Find the missing number in the third triad:
* **Triad 1:** $(7, 14, 21)$
* **Triad 2:** $(9, 18, 27)$
* **Triad 3:** $(11, 22, ?)$

**Answer Options:**
* **(A)** 31
* **(B)** 33
* **(C)** 35
* **(D)** 44

**Correct Answer:** **(B) 33**  
**Mathematical Solution:**
* Each triad follows the multiples of the base number:
  * Triad 1: $7 \times 1 = 7, 7 \times 2 = 14, 7 \times 3 = 21$.
  * Triad 2: $9 \times 1 = 9, 9 \times 2 = 18, 9 \times 3 = 27$.
  * Triad 3: $11 \times 1 = 11, 11 \times 2 = 22, 11 \times 3 = \mathbf{33}$.
Hence, the missing value is **33**.
