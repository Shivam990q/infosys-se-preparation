## ⚡ Master Reasoning Strategies & High-Yield Rules

### 1. Syllogisms Rules
* **Definite vs Possibility**: If a conclusion is definitely true from the basic Venn diagram, it follows. If it says "is a possibility", check if an alternate valid diagram can satisfy it without violating statements.
* **Complementary Pairs (Either-Or)**:
  1. Both conclusions must be individually false (cannot be determined).
  2. Subject and predicate must be identical.
  3. One conclusion must be positive and one negative (`Some + No` or `All + Some Not`).

### 2. Blood Relations Shorthand
* Use `+` for Male, `-` for Female.
* Use `=` for Married Couple, `—` for Siblings, and `|` (vertical line) for parent-child generation step.
* Trace from the end of the statement backwards when solving "pointing to a person" questions.
