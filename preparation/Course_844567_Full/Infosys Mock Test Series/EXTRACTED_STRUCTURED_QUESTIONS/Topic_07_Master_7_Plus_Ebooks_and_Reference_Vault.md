## 3. High-Yield Formulas & Algorithmic Rules Summary

### Quantitative Aptitude Key Formulas
- **Boats & Streams**: Downstream Speed = $u + v$, Upstream Speed = $u - v$. Speed of Boat = $\frac{D + U}{2}$, Speed of Stream = $\frac{D - U}{2}$.
- **Time & Work**: If A completes work in $x$ days and B in $y$ days, combined rate = $\frac{1}{x} + \frac{1}{y} = \frac{x+y}{xy}$, Total Days = $\frac{xy}{x+y}$.
- **Percentage Change**: $\text{Percentage Increase/Decrease} = \frac{\text{Difference}}{\text{Original Value}} \times 100\%$.

### Pseudo Code Execution Heuristics
- **Static Scope**: Static variables retain values across recursive and function calls; constructors execute upon each instantiation.
- **Bitwise Ops**: `x & (x - 1)` clears lowest set bit; `x ^ x = 0`; `x << k = x * 2^k`.
